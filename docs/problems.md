# Here you have quick solutions for most common known errors:
This page lists common issues and how to fix them.

## 1. Game crashes while starting with message:
> Multiple mods tried to register custom action handler for Simple Hardcore Respawn. To avoid this error, try deleting conflicted mods or choose one in config/ultraconfig/lorelink.json file in duplicate_strategy field.

### Possible cause:
You installed more than one extensions to the same mod.

### Solution:

Do exactly what is said in message. [Go here](./config_guide.md#-duplicate-strategy) to get more info about this config.
